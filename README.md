# SUSCC Adjunct Instructor Tracking System

A full-stack web application for tracking adjunct instructors across multiple departments, semesters, and campuses at Southern Union State Community College (SUSCC).

## Overview

This system manages semester-based reporting where department chairs submit lists of adjunct instructors via token-based links, and administrators compile campus-specific reports for appreciation packages.

### Key Features

- **Admin Dashboard**: Manage campuses, departments, chairs, and semester requests
- **Token-Based Submissions**: Department chairs submit via secure links (no login required)
- **Multi-Campus Support**: Track instructors teaching at multiple campuses
- **Automated Emails**: SendGrid integration for requests and reminders
- **Campus Reports**: Generate and export reports by campus
- **Historical Data**: Preserve all historical submissions

### Technology Stack

**Frontend:**
- React 18+ with Vite
- Tailwind CSS (SUSCC brand colors)
- React Router v6
- React Hook Form + Zod validation
- Axios for API calls

**Backend:**
- Python 3.11+ with FastAPI
- SQLAlchemy 2.0 ORM
- SQLite database (upgradeable to PostgreSQL)
- Alembic for migrations
- JWT authentication for admins
- SendGrid for email delivery

## Getting Started

### Prerequisites

- Python 3.11+
- Node.js 18+
- Git

### Installation

1. **Clone the repository**
```bash
git clone <repository-url>
cd adjunct-tracker
```

2. **Backend Setup**
```bash
cd backend
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# Edit .env with your configuration
alembic upgrade head
python seed_data.py  # Seed initial campuses and admin user
```

3. **Frontend Setup**
```bash
cd frontend
npm install
cp .env.example .env
# Edit .env with your API URL
```

### Running Locally

**Backend (Terminal 1):**
```bash
cd backend
source venv/bin/activate
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

**Frontend (Terminal 2):**
```bash
cd frontend
npm run dev
```

Access the application at: `http://localhost:5173`

API documentation: `http://localhost:8000/docs`

## Key Workflows

### Admin Workflow
1. Create semester request (Fall 2025)
2. System sends emails to all department chairs
3. Track submissions on dashboard
4. Send reminders to pending departments
5. View campus reports when ready
6. Export CSV or print reports

### Department Chair Workflow
1. Receive email with secure token link
2. Click link to access submission form
3. Copy from previous semester or start fresh
4. Add/edit adjunct instructors with campus and course assignments
5. Review and submit
6. Receive confirmation email

## Configuration

### Environment Variables

See `.env.example` files in both `backend/` and `frontend/` directories.

Key variables:
- `SECRET_KEY`: Application secret (generate with `openssl rand -hex 32`)
- `SENDGRID_API_KEY`: SendGrid API key for emails
- `DATABASE_URL`: Database connection string
- `FRONTEND_URL`: Frontend URL for CORS
