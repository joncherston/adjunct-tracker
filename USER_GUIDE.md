## Introduction

Welcome to the SUSCC Adjunct Instructor Tracker! This system helps Southern Union State Community College efficiently manage adjunct instructor information across all campuses and departments.

### What This System Does

- **Collects** adjunct instructor data from department chairs each semester
- **Tracks** submission status and sends automated reminders
- **Compiles** comprehensive reports showing all adjuncts by department
- **Identifies** instructors teaching in multiple departments
- **Exports** data for further analysis and record-keeping

### Who Uses This System

**Administrators** (Adjunct Faculty Committee members):
- Create semester requests
- Manage departments and chairs
- Track submissions
- Generate reports

**Department Chairs**:
- Receive email requests
- Submit adjunct instructor lists
- No login required (uses secure email link)

## Administrator Guide

### Dashboard Overview

When you log in, you'll see the Dashboard with:

1. **Active Requests** - Number of current semester requests
2. **Campuses** - Total campuses configured
3. **Departments** - Number of departments in the system
4. **Quick Actions** - Buttons for common tasks

### Initial Setup (One-Time)

Before creating semester requests, you need to set up:

#### 1. Campus Management

**Purpose**: Define your physical campus locations

**Steps:**
1. Click "Manage Campuses" from the Dashboard
2. Click "Add Campus"
3. Enter campus name (e.g., "Wadley Campus", "Opelika Campus", "Valley Campus")
4. Click "Add Campus" to save
5. Repeat for each campus

**Notes:**
- Campus names can be edited later
- Deleting a campus will hide it (not permanently delete)
- Campuses are used to organize departments

#### 2. Department Chair Management

**Purpose**: Store contact information for department chairs

**Steps:**
1. Click "Manage Chairs" from the Dashboard
2. Click "Add Department Chair"
3. Fill in:
   - Full Name (e.g., "Dr. Jane Smith")
   - Email Address (where they'll receive semester requests)
4. Click "Add Chair" to save
5. Repeat for each department chair

**Notes:**
- Emails must be valid (system sends automated emails here)
- Chairs can be assigned to multiple departments
- Update email if a chair changes

#### 3. Department Management

**Purpose**: Connect departments to campuses and chairs

**Steps:**
1. Click "Manage Departments" from the Dashboard
2. Click "Add Department"
3. Fill in:
   - Department Name (e.g., "English", "Mathematics", "Nursing")
   - Select Campus (from dropdown)
   - Select Department Chair (from dropdown)
4. Click "Add Department" to save
5. Repeat for each department

**Notes:**
- Each department belongs to one campus
- Each department has one assigned chair
- Chairs can oversee multiple departments

### Creating a Semester Request

**When to do this**: At the beginning of each semester when you need adjunct data

**Steps:**

1. **Navigate to Create Request**
   - From Dashboard, click "Create Semester Request"

2. **Basic Information**
   - **Semester Type**: Select Fall, Spring, Summer I, or Summer II
   - **Year**: Enter the year (e.g., 2024)
   - **Deadline**: Set the date by which chairs must submit
   - **Custom Message** (optional): Add special instructions or context

3. **Select Departments**
   - Check the boxes for departments to include in this request
   - You can select all or specific departments
   - Only active departments are shown

4. **Review Summary**
   - Verify semester information is correct
   - Check that you've selected the right departments
   - Review the custom message if you added one

5. **Send Requests**
   - Click "Send Semester Requests"
   - Confirm when prompted
   - Emails are sent automatically to all selected department chairs
   - You'll see a success message

**What happens next:**
- Each department chair receives an email with:
  - Semester information
  - Submission deadline
  - Your custom message (if any)
  - A unique secure link to their submission form

### Tracking Submissions

**Purpose**: Monitor which departments have submitted and send reminders

**Steps:**

1. **Open Tracking Dashboard**
   - Click "Track Semesters" from the Dashboard

2. **Select Semester**
   - Choose the semester you want to track from the dropdown
   - The most recent semester is selected automatically

3. **View Status**
   - **Green checkmark** = Submitted
   - **Yellow clock** = Pending (not yet submitted)
   - **Submission date** shows when completed
   - **Last reminded** shows if/when reminder was sent

4. **Send Reminders**
   - Click "Send Reminders" button
   - Select departments that need reminders (or select all pending)
   - Confirm the action
   - Reminder emails are sent immediately

**Best Practices:**
- Check tracking daily as deadline approaches
- Send first reminder 5 days before deadline
- Send final reminder 1-2 days before deadline
- Follow up personally with non-responders after deadline

### Viewing Reports

**Purpose**: See all submitted adjunct data and export for records

**Steps:**

1. **Navigate to Reports**
   - Click "View Reports" from Dashboard

2. **Select Semester**
   - Choose the semester from the dropdown
   - Report loads automatically

3. **View Statistics**
   - **Total Adjuncts**: Count of all submitted instructors
   - **Departments Submitted**: How many departments have reported
   - **Multi-Department**: Instructors teaching in multiple departments (flagged)

4. **Filter by Department** (optional)
   - Use the dropdown to show only one department
   - "All Departments" shows complete list

5. **Review Data**
   - Table shows: Department, Name, Email, Status
   - Yellow highlighted rows = Multi-department instructors
   - These instructors appear multiple times (once per department)

6. **Export or Print**
   - **Export CSV**: Click to download Excel-compatible file
   - **Print**: Click for print-optimized view (or Ctrl+P)

**Using CSV Export:**
- Opens in Excel, Google Sheets, or any spreadsheet program
- Contains all data from the report
- Useful for further analysis or mail merges

## Department Chair Guide

### Receiving the Request

You'll receive an email from the SUSCC Adjunct Faculty Committee with:
- Subject line indicating the semester
- Deadline for submission
- Any custom message from the committee
- A unique link to your submission form

**Important**: Save this email! The link is your only way to access the form.

### Accessing Your Submission Form

1. Click the link in the email
2. The page loads automatically (no login needed)
3. You'll see:
   - Semester information
   - Your department name
   - Submission deadline
   - Any special instructions
   - Current list of adjuncts (if any)

### Adding Adjunct Instructors

You have two options:

#### Option 1: Copy from Previous Semester (Faster)

1. Click the "Copy from Previous" button
2. A list of available previous semesters appears
3. Select the semester you want to copy from
4. Click "Copy" next to that semester
5. All adjuncts from that semester are added to your current list
6. Review the list and remove/add as needed

**When to use this:**
- Most of your adjuncts are returning from last semester
- You want to save time
- You'll still need to add new instructors or remove departures

#### Option 2: Add Manually

1. Click the "Add Adjunct" button
2. Enter the instructor's full name
3. Enter their email address
4. Click "Add Adjunct" to save
5. The instructor appears in your list
6. Repeat for each instructor

**Tips for manual entry:**
- Use full legal names (e.g., "John Michael Smith" not "Mike Smith")
- Double-check email addresses (system will show error if invalid)
- Use institutional email if available

### Editing Your List

**Removing an instructor:**
1. Find the instructor in your list
2. Click the red trash icon next to their name
3. Confirm the removal
4. They're removed immediately

**Adding more instructors:**
1. Click "Add Adjunct" button again
2. Enter information
3. Repeat as needed

### Submitting Your List

**Before you submit, verify:**
- All adjunct instructors are included
- Names are spelled correctly
- Email addresses are correct
- No duplicate entries

**To submit:**
1. Click the yellow "Submit Request" button at the bottom
2. Read the confirmation message carefully
3. Click "OK" to confirm

**After submission:**
- You'll see a green success banner
- The page shows "Submitted Successfully"
- **You cannot make changes after this point**
- If you need to change something, contact the administrator

### What If I Need to Make Changes After Submitting?

Contact the Adjunct Faculty Committee immediately:
1. Explain what needs to be changed
2. Provide the corrected information
3. An administrator can reset your submission if necessary
4. You'll receive a new email with a fresh link

## Common Tasks

### Admin: Resetting a Chair's Submission

If a department chair submitted by mistake or needs to make changes:

1. This requires direct database access (contact IT support)
2. Alternatively, create a new semester request for that department only
3. Or manually update the data in reports after receiving corrections

### Admin: Adding a New Department Mid-Semester

1. Go to "Manage Departments"
2. Add the new department
3. Go to the semester tracking page
4. The new department won't be in this semester's request
5. You'll need to send them a separate request (create a new semester request with just that department)

### Admin: Changing a Department Chair's Email

1. Go to "Manage Chairs"
2. Find the chair
3. Click edit
4. Update the email
5. Save changes
6. Future emails will go to the new address
7. Active requests still use the old email (can't be changed mid-semester)

### Chair: Accessing Form If Email Was Deleted

1. Contact the Adjunct Faculty Committee
2. Request a new link
3. An admin can resend the email or provide the link directly

## Troubleshooting

### Problem: "Invalid or expired access token" (Chairs)

**Causes:**
- Link was copied incorrectly (missing characters)
- Semester request was deleted by admin
- Link is from a very old request

**Solutions:**
1. Verify you copied the entire URL from the email
2. Contact the Adjunct Faculty Committee for a new link
3. Check if you're using the correct semester's email

### Problem: "Cannot log in" (Admins)

**Causes:**
- Incorrect password
- Caps Lock is on
- Email address typed incorrectly

**Solutions:**
1. Check Caps Lock
2. Verify email is correct
3. Use "Forgot Password" link
4. Contact IT Support for password reset

### Problem: "This request has already been submitted" (Chairs)

**Causes:**
- You already submitted (confirmation banner should show)
- This is the expected behavior to prevent duplicate submissions

**Solutions:**
1. If you submitted by mistake, contact the administrator
2. If you need to make changes, ask admin to reset your submission
3. Otherwise, your job is done! No action needed.

### Problem: "Failed to load data"

**Causes:**
- Internet connection issue
- Server maintenance
- Browser compatibility

**Solutions:**
1. Check your internet connection
2. Refresh the page (F5 or Ctrl+R)
3. Try a different browser
4. Clear browser cache and cookies
5. Contact IT Support if problem persists

### Problem: "Email not sending" (Admins)

**Causes:**
- Email service (Brevo) API key issue
- Recipient email address invalid
- System configuration problem

**Solutions:**
1. Verify department chair email addresses are correct
2. Check system logs (contact IT Support)
3. Verify Brevo API key is configured correctly
4. Check spam folders

## FAQs

### General Questions

**Q: Is this system secure?**
A: Yes. Admin access requires login with password. Chair access uses unique, non-guessable tokens sent via email. All data is encrypted in transit (HTTPS).

**Q: What happens to old semester data?**
A: All data is retained indefinitely. You can view reports from any past semester.

**Q: Can department chairs see other departments' submissions?**
A: No. Each chair only has access to their own department's form.

**Q: What if someone is an adjunct in multiple departments?**
A: Each department submits them separately. The system automatically flags multi-department instructors in reports (shown in yellow).

### For Administrators

**Q: Can I edit a submission after it's been submitted?**
A: Not through the web interface. Contact IT Support for direct database edits if absolutely necessary.

**Q: Can I send requests to some departments now and others later?**
A: Yes. Create separate semester requests. The system allows multiple requests for the same semester period.

**Q: What if a department chair leaves mid-semester?**
A: Update their email in "Manage Chairs". For active requests, the old email still has access. You can manually send the link to the new chair.

**Q: Can I delete a semester request?**
A: Yes, but carefully. Deleting a request removes all associated data. It's better to leave it and create a new one if needed.

**Q: How do I add more admins?**
A: Contact IT Support. Admin accounts must be created in the database with proper permissions.

### For Department Chairs

**Q: Do I need to create an account?**
A: No. You access the form through the unique link sent to your email. No username or password needed.

**Q: Can I save my progress and come back later?**
A: Yes! The form saves as you go. Your adjuncts are saved as soon as you add them. Come back anytime using the same link.

**Q: What if I don't have any adjuncts this semester?**
A: Still submit the form (even with zero adjuncts). This lets the committee know you responded.

**Q: Can someone else submit for my department?**
A: Yes. Forward the email with the link to whoever needs to complete it. Only one submission per department is allowed.

**Q: What if I forgot to include someone?**
A: If you haven't submitted yet, just add them. If you already submitted, contact the administrator immediately to reset your submission.

**Q: Why can't I remove or add instructors after submitting?**
A: This prevents accidental changes and ensures data integrity. Once submitted, the list is official and locked.

## Best Practices

### For Administrators

1. **Plan Ahead**
   - Send requests 2-3 weeks before you need the data
   - Account for holidays and breaks

2. **Clear Communication**
   - Use the custom message field to explain context
   - Include contact information for questions

3. **Regular Monitoring**
   - Check tracking daily as deadline approaches
   - Send reminders to non-responders

4. **Data Quality**
   - Review reports for obvious errors
   - Follow up on suspicious entries
   - Check multi-department instructors with chairs

5. **Record Keeping**
   - Export CSV of final reports
   - Print copies for physical files
   - Document any manual corrections

### For Department Chairs

1. **Respond Promptly**
   - Don't wait until the deadline
   - Aim to submit within one week

2. **Accuracy First**
   - Verify names and emails
   - Use full legal names
   - Double-check before submitting

3. **Use Copy Feature Wisely**
   - Great for returning instructors
   - Always review the copied list
   - Remove departures, add newcomers

4. **Keep Records**
   - Save or screenshot the confirmation
   - Keep the original email
   - Note the submission date

5. **Communicate**
   - Ask questions if unsure
   - Reply to the request email with questions
   - Alert administrator to any special circumstances

## Appendix: System Workflow

### Complete Process Flow

1. **Setup Phase** (One-time)
   - Admin configures campuses
   - Admin adds department chairs
   - Admin creates departments

2. **Request Phase**
   - Admin creates semester request
   - System sends emails to department chairs
   - Chairs receive unique links

3. **Submission Phase**
   - Chairs access forms via email links
   - Chairs add adjunct instructors
   - Chairs submit final lists

4. **Tracking Phase**
   - Admin monitors submission status
   - Admin sends reminders to pending departments
   - Admin follows up with non-responders

5. **Reporting Phase**
   - Admin views compiled reports
   - Admin exports data
   - Admin generates records for distribution

6. **Repeat**
   - Process repeats each semester
   - Historical data remains accessible
